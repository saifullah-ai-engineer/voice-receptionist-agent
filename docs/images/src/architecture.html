HOW IT FITS TOGETHER

From a call to a reply

One config file drives the whole agent. Text works out of the box, no paid API, no phone line.

01  CALLER

INTEGRATION POINT

Phone line

A telephony provider (for example Twilio) puts speech-to-text in front of the agent. Not included in this repo.

WORKS TODAY

Text input

CLI call or demo, no phone line needed.

python -m voice_receptionist_agent "..."
→

02  AGENT, THIS REPO

CONFIG

business.json

One file: name, services, hours, price note, handoff message, phone. Strict validation, a bad file fails with a named error.

LANGGRAPH

StateGraph, five nodes

greet, classify, collect, route, draft. Compiled once per process, reused for every call.

CLASSIFIER

Rule-based, optional LLM hook

Keyword scores, longest service match first. If the hook fails or answers something unknown, the rules take over.

REPLY WRITER

replies.py

Drafts from business facts and caller words only. It never invents a price, hours, or availability.
